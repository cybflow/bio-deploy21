How Plans Work

Slug

Use free as the slug for the default plan. New users are automatically assigned whichever plan has the slug free when they sign up.

Home Page Visibility

Toggle the Visible / Hidden button to control whether each plan card appears in the pricing section on the public home page. Existing subscribers are unaffected.

Features

Enter one feature per line in the Features field. Each line becomes a bullet point on the home page pricing card. Leave blank for no bullet list.
